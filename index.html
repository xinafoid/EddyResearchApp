EtsyResearchApp

EtsyResearchApp is a private, read-only market research tool built for personal use. It helps one independent seller understand which product niches are active on Etsy so they can decide what to offer in their own shop.

What the app does

Using the Etsy Open API, the app reads publicly available shop and listing information, such as shop open date, public sales count, listing titles, prices and tags. It summarizes this data to show which niches and styles are trending.

What the app does not do

  • It does not create, edit or delete listings in any shop.
  • It does not send messages or email to any user.
  • It does not collect or store buyer or personal data.
  • It does not scrape Etsy pages. All data is requested through the official API.
  • It is not offered to the public and is not a commercial product.

Compliance

The app follows the Etsy API Terms of Use and the API Testing Policy, respects rate limits, and keeps its API credentials private and unshared.

Users

The only user is the app's developer.
