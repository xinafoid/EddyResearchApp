# EddyResearchApp
EddyResearchApp is a private, read-only research tool for one independent seller. It uses the Etsy Open API to read public shop and listing data (shop open date, sales count, listing titles, prices and tags) so the owner can analyze market trends and choose which product niches to enter.

It does not create, edit or delete listings. It does not send messages or email, does not store buyer data, and does not scrape Etsy pages. It follows Etsy's API Terms of Use, API Testing Policy and rate limits.

This project is not public and not commercial. The only user is the repository owner.
